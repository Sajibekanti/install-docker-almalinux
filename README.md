# 🚀 install-docker-almalinux

A simple and reliable script to install **Docker**, **Docker Compose**, **curl**, **git**, and **nano** on **AlmaLinux 8.x and 9.x**.

---

## 📦 What It Installs

- Docker CE (Community Edition)
- Docker Compose Plugin
- curl
- git
- nano

---

## 🧪 Tested On

- AlmaLinux 8.x
- AlmaLinux 9.x

---

## ⚡️ One-Line Install

```bash
curl -sSL https://raw.githubusercontent.com/Sajibekanti/install-docker-almalinux/main/install-docker-almalinux.sh | sudo bash
